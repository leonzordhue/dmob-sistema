# 🚧 DMOB - Sistema de Cadastro de Ramais

Sistema web para cadastro e gerenciamento de ramais rodoviários.

## 🚀 Como usar

1. Clone o repositório
2. Instale as dependências: `pip install -r requirements.txt`
3. Execute: `python app.py`
4. Acesse: http://localhost:5021
